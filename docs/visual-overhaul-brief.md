# Akshat City — Visual Overhaul: Audit, Diagnosis and Plan

Baseline: the stylised-cinematic pass committed to the working tree on 2026-10-23 (desktop-first, as decided).
No code is changed by this document. Measurements were taken in Chrome on the development machine at
2004×1092 render resolution (1.5× pixel ratio) with the user's second game tab closed.

## Stage 1 — Repository audit

### 1. Renderer, loop, lighting, camera, fog, post
| Concern | Where | What it does today |
| --- | --- | --- |
| Renderer init | `src/main.js` → `Game.boot()` | `WebGLRenderer` (antialias off; AA comes from SMAA), `ACESFilmicToneMapping`, exposure 1.0, sRGB output, `PCFSoftShadowMap`, pixel ratio capped 1.5 desktop / 1.25 low, adaptive 0.7–1.5 in `Game.adapt()`. |
| Render loop | `Game.frame()` | input → day/night lerp → cinematic *or* gameplay (vehicle, player, traffic, `physics.step`, pedestrians, effects, markers, missions, HUD, radar) → `post.render()` → adaptive DPR. Fixed 60 Hz physics with accumulator (`Physics.step`). |
| Lights | `Game.boot()` | One `DirectionalLight` sun (2.6, warm) with a 2048² shadow camera (±60 m) that follows the player each frame, one `HemisphereLight` (1.25). No other shadow casters. Night state in `Game.applyNight()` scales both plus env, fog, exposure and bloom. |
| Sky / environment | `Game.boot()` | Procedural gradient sky dome (`ShaderMaterial`, palette in `src/game/Palette.js`). Poly Haven HDRI is PMREM-filtered and used **only** as `scene.environment` (intensity 0.6) for reflections on the car, glass and water. |
| Fog | `Game.boot()` | `FogExp2`, horizon colour, density 0.0010 day → 0.0026 night. |
| Camera | `src/game/CameraRig.js` | Third-person chase (lag, speed-based distance and FOV, orbit on drag, auto-recentre) and first-person; `cinematic` mode used by the title orbit and fly-in in `Game.cinematicFrame()`. |
| Post-processing | `src/game/Postfx.js` → `createPostfx()` | `RenderPass` → `UnrealBloomPass` (0.18 / 0.25 / 0.9) → custom grade `ShaderPass` (split-tone, contrast 1.04, saturation 1.18, vignette, grain, lifted blacks) → `OutputPass` → `SMAAPass`. GTAO was removed after profiling. |

### 2. Building generation and world assets
- `src/game/CityMap.js`: 8×8 block grid (block 36 m, road 14 m, world 414 m), district table, collider registry, minimap painter, road graph.
- `src/game/City.js`: `buildGround()` (roads, markings, slabs), `buildBlocks()` → `lotsFor()`, `building()`, `house()`, `garage()`, `storefront()`, `windows()`, `rooftop()`; `buildPark()`, `buildBeach()`, `buildStadium()`, `buildLandmarks()`, `buildTrees()`, `buildStreetFurniture()`, `buildParkedCars()`, `buildDynamicProps()`. Everything is merged per material with `mergeGeometries` into ~13 meshes; lamps, traffic lights, benches, trees, palms, mountains and light pools are `InstancedMesh`.
- Materials: `src/game/Palette.js` (matte `MeshStandardMaterial`s, low-contrast noise and paving canvases, district palettes, sky colours). Window glass uses an `onBeforeCompile` hook so per-vertex colour becomes night emissive.
- Models: `public/assets/models/ferrari.glb` (three.js example, CC-BY, Draco, 359 k tris, player car only), `ferrari_lod.glb` (generated by `scripts/make-car-lod.mjs`, 10.7 k tris, all parked/traffic cars via `src/game/BgCars.js` instancing), `Soldier.glb` (three.js example / Mixamo, player + pedestrians).
- Textures still on disk: 19 Poly Haven 1k JPGs (12 MB). **After the stylised pass only `waternormals.jpg` and the HDRI are used, but `src/game/Assets.js` still downloads all of them.**

### 3. Character and vehicle integration
- `src/game/Player.js`: `makeSoldier()` clones the GLB with `SkeletonUtils`, `AnimationMixer` with Idle/Walk/Run blended by speed in `blendLocomotion()`; Rapier `KinematicCharacterController` on a capsule (autostep, snap-to-ground, pushes dynamic props).
- `src/game/Pedestrians.js`: 14 tinted clones walking block perimeters, mixers updated within 90 m, step-aside and panic reactions.
- `src/game/Vehicle.js`: Rapier `DynamicRayCastVehicleController` on a 1200 kg cuboid chassis, 4 wheels from the GLB wheel nodes, stiffness 150, handbrake lowers rear grip, impact detection from Δv, auto-upright, headlight spotlights at night. Visual model from `src/game/CarModel.js` (`prepareCar`, `buildPlayerCar`).
- `src/game/Traffic.js`: kinematic Rapier bodies following the road graph, instanced visuals, yield logic.
- `src/game/Physics.js`: static cuboids/cylinders from `CityMap.colliders`, 92 dynamic props (crates, cones, barrels), radial explosion impulses.

### 4. Cost profile (measured)
| View | GPU ms | Draw calls | Triangles |
| --- | --- | --- | --- |
| Skyline from Central Park | 6.6 | 345 | 2.44 M |
| Downtown street level | 8.0 | 219 | 2.44 M |
GPU memory indicators: 255 geometries, 96 textures, 50 shader programs. Largest single costs: player Ferrari (359 k tris, shadow-casting), window/trim merged meshes (~8.6 k windows, 232 k trim vertices), 14 skinned pedestrians (CPU mixers), PCFSoft 2048 shadow pass. Known CPU cost per frame ≈ 3 ms (physics 0.25 ms).

### 5. Asset formats, sizes, licences, loading
- `src/game/Assets.js`: one `LoadingManager`, Draco decoder from `public/draco/`, HDR via `RGBELoader`; progress drives the title-screen loading text. Boot payload ≈ 21 MB (HDR 5.2 MB, models 3.8 MB, textures 12 MB — 11 MB now unused). No KTX2, no meshopt at runtime.
- Licences: Poly Haven CC0; Ferrari CC-BY (credited in menu + `readme.md`); Soldier (Mixamo, via three.js examples). Draco decoder is Apache-2.0 (three.js).

### 6. Tests, state, persistence
- No automated tests, no test script, **not a git repository yet**.
- Game state lives on the `Game` instance; missions in `src/game/Missions.js` (state machine, callbacks into `UI`), progress in `src/game/Save.js` (`localStorage` key `akshat-city-save-v1`: missions, tokens, sound, intro flag).

## Stage 2 — Visual diagnosis (ranked)

| # | Weakness | Evidence | Proposed change | Files | Impact / GPU cost / risk |
| --- | --- | --- | --- | --- | --- |
| 1 | Skyline is boxes with one floor rhythm | Skyline shot: identical slab towers, flat roofs, no podium/crown hierarchy | Building kit: 6 typologies (point tower, slab, stepped setback, podium+tower, crown, low-rise courtyard), roof vocabulary, 2–3 landmark towers | `City.js` `lotsFor/building/rooftop`, `Palette.js` | High / ~+0.3 M tris / low |
| 2 | Facades: uniform punched windows | Street shot: same window grid on every style | Facade styles per typology: punched, ribbon bands, curtain wall with spandrels, residential bays with balconies, corner shops; entrance canopies | `City.js` `windows/storefront` | High / low / low |
| 3 | Player and pedestrians are photoreal military rigs | Soldier clashes with matte world | Replace with a stylised low-poly animated character (CC0, e.g. Quaternius/Kenney/Kay Lousberg packs); keep Mixamo-compatible clips | `Player.js`, `Pedestrians.js`, `Assets.js` | High / low / medium (retarget) |
| 4 | Roads and sidewalks are flat slabs | No curb profile, no verge, no manholes, uniform crosswalks | Curb bevel strip, grass verges in residential blocks, tree pits, manholes/drains decals, median planters downtown | `City.js` `buildGround` | Medium / low / low |
| 5 | Vegetation and furniture are repetitive | One tree blob, one lamp, no bushes | 3 tree species + bushes/hedges (instanced), bins, bus shelters, planters, hydrants | `City.js` `buildTrees/buildStreetFurniture` | Medium / ~+3 draw calls / low |
| 6 | Lighting lacks grounding | Buildings float visually; mountains are plain white cones | Bake vertex AO into merged geometry (darken bases, under ledges, window reveals), layered mountain silhouettes with haze bands, horizon glow | `City.js`, `main.js` sky shader | Medium / none / low |
| 7 | Background cars lack lights/glass | Instanced LOD is paint-only | Instanced emissive attribute for head/tail lights, darker glass vertex colour | `BgCars.js`, `scripts/make-car-lod.mjs` | Low / none / low |
| 8 | Camera is functional, not cinematic | No look-ahead or roll, abrupt mission start | Steering look-ahead, subtle roll, per-mission intro pan, fade-to-black transitions | `CameraRig.js`, `Missions.js`, `UI.js` | Medium / none / low |
| 9 | HUD is clean but generic | Default type sizes, no mission title card | Mission title card, district typography, radar icons, consistent 8-pt spacing | `index.html`, `style.css`, `UI.js` | Low / none / low |
| 10 | Loading is heavy and plain | 21 MB payload, 11 MB unused, text-only loader | Stop loading photo PBR sets, delete unused JPGs, KTX2 for what remains, designed loading screen with progress bar and fade | `Assets.js`, `public/assets`, `index.html` | Medium / none / low |

## Stage 3 — Implementation plan

Each milestone is one small, reviewable change set with its own build + verification.

| Milestone | Scope | Acceptance criteria |
| --- | --- | --- |
| M0 Baseline | `git init`, commit current tree, add `window.captureViews()` dev hook that places the camera at 4 fixed views and logs GPU ms / calls / tris | Repo committed; 4 reference screenshots + metrics recorded |
| M1 Asset diet | Remove photo PBR loads from `Assets.js`, delete unused JPGs, keep HDR + water normals | Boot payload ≤ 10 MB; title screen interactive ≤ 2 s on a fast connection; no visual change |
| M2 Building kit v1 | Typologies + facade styles + roofs (#1, #2) | Skyline view shows ≥ 5 distinct silhouettes; draw calls ≤ 360; tris ≤ 3.2 M; GPU ≤ 9 ms |
| M3 Street kit | Curbs, verges, pits, manholes, planters (#4) | Street view approved; calls ≤ 380; no collider regressions (drive loop test) |
| M4 Vegetation & furniture | 3 tree species, bushes, props (#5) | ≤ +4 draw calls; park view approved |
| M5 Character swap | Stylised rig for player + peds (#3) | Idle/walk/run blend, enter/exit car, no T-pose; mixer CPU ≤ 2 ms with 14 peds |
| M6 Lighting lock | Vertex AO bake, mountains, sky/grade finalised (#6) | Day and night reference shots approved; single sun + hemi retained |
| M7 Camera & transitions | Look-ahead, mission intro pans, fades, loading screen (#8–#10) | Mission start/finish flow feels continuous; no control regressions |
| M8 Performance & fallbacks | Quality presets Auto/Low/Medium/High in the menu; low = no shadows, no post, 8 peds | Desktop p95 ≤ 20 ms at 1.5× DPR; low preset ≤ 33 ms on a mid phone; WebGPU evaluated only on a separate branch if a feature needs it |

## Stage 4 — Verification per milestone
1. `npm run build` passes; no console errors on load.
2. Manual loop: walk, enter car, drive a lap, handbrake drift, exit, first/third camera, night toggle, start and finish one mission, collect a token, hit a barrel, open map/dossier/résumé mode, reload and confirm persistence.
3. Fixed-view screenshots (skyline, downtown street, Grove Street, pier) compared with the previous milestone.
4. Record GPU ms (gl.finish timing), draw calls, triangles, texture count for each view; dense traffic and night runs included.
5. Note unsupported features: WebGL2 required (no WebGL1 fallback); Rapier WASM required; touch controls exist but phones are out of scope until M8.
